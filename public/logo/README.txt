ChromaType logo package

Recommended system: Concept 1 — Monogram Fusion

Canonical flat accent: #5966D9
Ink: #171923
Coral secondary: #C85048
Cool neutral: #8A94A6
Dark UI background: #0B0B0F

Construction:
- 64 × 64 symbol grid
- 8-unit base module
- Rounded terminals / consistent mass
- Inter outlines for the wordmark (font-independent SVG paths)

Accessibility:
- The logo is not itself subject to WCAG text contrast requirements.
- The canonical accent #5966D9 exceeds 3:1 non-text graphical contrast against both #FFFFFF and #0B0B0F.
- Use white wordmarks on dark surfaces and ink wordmarks on light surfaces.

Usage:
Maintain clear space equal to 1× the T-stem width around the mark; minimum symbol size is 16 px and minimum horizontal lockup height is 24 px.

Gradient file is secondary only; do not use it as the primary identity.
